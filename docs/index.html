версия 0.16.4 · zip, 136 МБ
  1. Распакуй архив в обычную папку, например C:\Programs\KabanMusic (не запускай прямо из архива).
  2. Запусти KabanMusic.exe. Если Windows покажет синее окно «Система Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае»: у программы просто нет платной цифровой подписи.
  3. Дальше обновления ставятся из самого приложения: Настройки → Обновления.

Все версии и что в них нового — на GitHub.
