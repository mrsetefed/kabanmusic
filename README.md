# KabanMusic

Музыкальный плеер для Windows. Ищет музыку в **YouTube Music**, **VK Музыке** и **локальных файлах** из одного окна. Свои плейлисты могут содержать треки из разных источников.

[Скачать последнюю версию](https://github.com/mrsetefed/kabanmusic/releases/latest) · [Сайт](https://mrsetefed.github.io/kabanmusic/) · [Сообщить об ошибке](https://github.com/mrsetefed/kabanmusic/issues)

## Что умеет

| Возможность | Как работает |
| --- | --- |
| Единый поиск | Плеер объединяет результаты доступных источников. Папки с музыкой нужно добавить в библиотеку, а для доступа к своей музыке и плейлистам сервиса нужен вход в соответствующий аккаунт. |
| Свои плейлисты | Плейлисты YouTube Music и VK можно скопировать в новый список либо добавить в существующий через «Перенести в…». В своём списке для этого есть «Объединить с…». При объединении одинаковые треки одного источника пропускаются. |
| Очередь и воспроизведение | Есть перемешивание, повтор трека или очереди, радио по треку и автоплей после окончания очереди. Для недоступного трека можно подобрать замену. |
| Мини-плеер | Закрепляется поверх обычных окон Windows. В нём есть лайк, повтор, перемотка и громкость. После начала воспроизведения доступны системные медиаклавиши. |
| Локальная музыка | Плеер индексирует выбранные папки, показывает скачанное и поддерживает редактирование локального аудио. |
| Last.fm | После подключения доступны скробблинг и рекомендации. |
| Discord | Rich Presence показывает, что играет. Для трека с идентификатором YouTube кнопка «Подслушать» позволяет открыть тот же трек примерно с той же секунды. |

## Установка и обновление

1. Открой [последний релиз](https://github.com/mrsetefed/kabanmusic/releases/latest) и скачай файл `KabanMusic-<версия>-win.zip` из раздела **Assets**.
2. Распакуй весь архив в постоянную папку, куда у твоего пользователя есть право записи.
3. Запусти `KabanMusic.exe` из распакованной папки. При запуске приложение добавляет ярлык в меню «Пуск» текущего пользователя.
4. Для последующих обновлений открой **Настройки → Обновления**. Если обновляешь вручную, закрой приложение и распакуй новую версию целиком.

Опубликованная сборка предназначена для Windows x64. Профиль хранится отдельно от программы в `%APPDATA%\KabanMusic`. Для ручного отката доступны [предыдущие релизы](https://github.com/mrsetefed/kabanmusic/releases). Чтобы сверить архив, сравни SHA-256 с дайджестом файла в GitHub Releases:

```powershell
Get-FileHash .\KabanMusic-0.18.6-win.zip -Algorithm SHA256
```

## Первые шаги

- **Музыка с компьютера.** В настройках подключений добавь нужные папки. После индексации файлы появятся в библиотеке и поиске.
- **YouTube Music и VK.** Подключи аккаунты в настройках. Их списки появятся отдельными сворачиваемыми группами на левой панели.
- **Объединение.** Открой свой список и нажми «Объединить с…» или открой список сервиса и нажми «Перенести в…». Существующая очередь треков в своём списке остаётся на месте, а новые треки добавляются в конец.
- **Discord.** Включи Rich Presence в настройках и открой настольный клиент Discord. Для треков без обложки используется [анимированная пластинка](https://mrsetefed.github.io/kabanmusic/assets/kaban_no_cover.gif).

## Как собрать Windows-архив с правками

1. Понадобится Python 3. Внешние Python-пакеты для скрипта не нужны.
2. Скачай [базовый архив 0.18.3](https://github.com/mrsetefed/kabanmusic/releases/download/v0.18.3/KabanMusic-0.18.3-win.zip) и положи его в корень клона, рядом с README. SHA-256 базового архива — `c5d23575e5ce92737f256318485372e06552a2fc3931033486c628a109e0c488`.
3. Выполни команды из корня репозитория:

```powershell
python tools/build_playback_fix.py --version 0.18.6 --ui-fix
python -m zipfile -t KabanMusic-0.18.6-ui-fix-win.zip
```

Скрипт заменяет нужные части `app.asar`, обновляет его контрольные суммы и записывает отдельный ZIP. Чтобы подготовить архив для стабильного канала, имя файла в релизе должно быть `KabanMusic-<версия>-win.zip`, тег — `v<версия>`, а номер внутри приложения должен совпадать с тегом. Автообновление читает последний стабильный GitHub Release. Сохраняй предыдущий релиз для ручного отката и проверяй, что новая версия открывается через [Latest](https://github.com/mrsetefed/kabanmusic/releases/latest).

## Данные и отчёты об ошибках

Локальный профиль может содержать настройки, историю, плейлисты, данные входа и журналы. Для отчёта об ошибке достаточно версии приложения, версии Windows и шагов воспроизведения. Если прикладываешь журнал или скриншот, убери из него личные пути, данные аккаунта и секреты. Обычный баг можно описать в [Issues](https://github.com/mrsetefed/kabanmusic/issues). Если найдёшь проблему, из-за которой раскрываются данные входа, сначала свяжись с владельцем проекта в личном сообщении и передай только обезличенное описание.

В репозитории пока нет отдельного файла лицензии. Права на сторонние компоненты определяются их собственными лицензиями. Условия для файлов проекта ещё предстоит зафиксировать отдельно.
